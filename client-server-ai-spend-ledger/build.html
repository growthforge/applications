Architecture

Three feeds, one ledger, one rule: the invoice is the source of truth. Gateway counts never add cost; they decide whose cost a billed line is and whether the gateway saw everything the bill charges for.

  1. Gateway metering

    API Management's llm-emit-token-metric sends prompt, completion and cached tokens to Application Insights with team, use case, environment and deployment. llm-token-limit sets the near-real-time limits.

  2. Cost export

    Azure Cost Management's daily FOCUS export, documented with FOCUS 1.2 column names S7. Claude in Microsoft Foundry is billed as one aggregated Claude Consumption Unit line S10. The pack's file is shaped like that export.

  3. Ledger

    Every row normalised to FOCUS 1.4 names with token columns shaped like the FOCUS 1.5 draft; the bill allocated by gateway shares, retrieval calls and tags; the list-price estimate reconciled to the bill.

  4. Join with outcomes

    Runs, successes, failures, retries, discards and review minutes per use case and day: the business half of cost per successful outcome.

  5. Pack and pipeline

    The monthly memo, owner budgets and alerts, the scale, fix or stop calls and the savings pipeline with its next-bill checks.

# FOCUS mapping for the AI spend ledger

Every column the ledger reads or writes, the FOCUS version it comes from, and how the ledger uses it. The organisation and its data are illustrative.

## Versions, plainly

| Version | Status (read 3 Nov 2026) | What the ledger does with it |
|---|---|---|
| FOCUS 1.2 | Azure Cost Management's FOCUS export is documented up to the 1.2-preview dataset (some 1.2 fields not yet populated). | The illustrative export `data/focus_export.csv` is shaped like an Azure FOCUS export: FOCUS 1.2 column names, daily rows, one constant illustrative rate per SKU. It is synthetic, not an export. |
| FOCUS 1.4 | Current specification, ratified 4 June 2026. No token columns. Removes ProviderName and PublisherName. | The ledger normalises every row to FOCUS 1.4 column names (`ledger/normalise.js`). |
| FOCUS 1.5 | Planned for ratification on 3 Dec 2026, so not current. The working draft adds token direction, token cache action and model identity (ModelDeveloper, ModelFamily, ModelId, ModelVersion). | Token fields ride as `x_` extension columns shaped like the draft names, so moving to 1.5 is a rename. |

Sources: FOCUS 1.4 announcement and the 1.5 release scope page (focus.finops.org), Microsoft Learn's FOCUS cost and usage dataset schema.

## Gateway metrics, mapped

The API Management policy emits prompt, completion and total tokens (cached tokens in preview) with four dimensions: team, use-case, environment and deployment. The daily aggregate in `data/token_metrics.csv` becomes FOCUS-aligned estimate rows: one row per token class, `ConsumedUnit` Tokens, `ServiceCategory` AI and Machine Learning, the `x_` columns above, and `ListCost` = tokens times the published list price. These rows never join the bill. They decide each team's share of a billed line and feed the reconciliation.

## What is not modelled

Following the FOCUS 1.5 release scope, these stay outside the ledger: reasoning tokens billed but not returned, input modality (image and audio pricing), context-window-based pricing, priority and batch tiers as separate SKUs, provisioned throughput detail and agentic subcategories. Claude in Foundry arrives as one aggregated CCU line, so its token classes come from the gateway, not the bill.

Gateway limits

  • Production, soft. No monthly quota, because a quota answers 403 and would stop customer work. The emitted metric drives an hourly alert at 80% and 100% of each use case's allowance; a high tokens-per-minute ceiling (429) still stops runaway loops S9.
  • Outside production, hard. Tokens per minute and a monthly quota per subscription and model.
  • Keyed by subscription and model. Each use case has its own subscription, and its name carries team, use case and environment, so a caller cannot charge another team.
azure/apim-ai-gateway.policy.xml: the gateway policy, commented line by line (not deployed)
<!--
  AI gateway policy for the illustrative organisation (a FinTech on Azure, made up for this pack).
  Applied at API scope to the Azure OpenAI and Claude APIs in API Management.

  Status: NOT DEPLOYED. Written against the Microsoft Learn policy reference pages for
  llm-token-limit (page dated 1 April 2026) and llm-emit-token-metric (page dated 15 September 2026),
  element and attribute names as documented there. Well-formed XML (checked with xmllint); policy
  expressions use XML entities for quotes, which API Management decodes before evaluating them.

  Convention: every team and use case gets its own API Management subscription, named
  team.use-case.environment, for example customer-ops.support-assistant.prod. The gateway reads
  team, use case and environment from that name, so a caller cannot charge another team by
  sending a header. Subscriptions are created by the platform team, not by callers.

  What it does:
    1. Labels each call with team, use case, environment and deployment.
    2. Production: soft limits. No monthly quota (a quota answers 403 and would stop customer work);
       the monthly allowance is watched by an alert on the emitted metric at 80% and 100%
       (kql/soft-quota-alert.kql). A high tokens-per-minute ceiling (429) still stops runaway loops.
    3. Outside production: hard limits. Tokens per minute (429) and a monthly token quota (403).
    4. Emits token counts to Application Insights with those four dimensions, which the ledger joins
       to the bill to split shared lines between teams.
-->
<policies>
  <!-- inbound: runs before the request is forwarded to the model backend -->
  <inbound>
    <!-- base: apply the product and global policies first (authentication, IP filtering) -->
    <base />
    <!-- team: first part of the subscription name; unknown when the name does not follow the convention -->
    <set-variable name="team" value="@{ var p = (context.Subscription?.Name ?? &quot;&quot;).Split('.'); return p.Length == 3 ? p[0] : &quot;unknown&quot;; }" />
    <!-- use-case: second part of the subscription name -->
    <set-variable name="useCase" value="@{ var p = (context.Subscription?.Name ?? &quot;&quot;).Split('.'); return p.Length == 3 ? p[1] : &quot;unknown&quot;; }" />
    <!-- environment: third part; anything other than prod is treated as non-production, so the hard limits apply -->
    <set-variable name="environment" value="@{ var p = (context.Subscription?.Name ?? &quot;&quot;).Split('.'); return p.Length == 3 &amp;&amp; p[2] == &quot;prod&quot; ? &quot;prod&quot; : &quot;nonprod&quot;; }" />
    <!-- deployment: the Azure OpenAI deployment from the URL template /openai/deployments/{deployment-id}/...; the Claude API uses a single named backend -->
    <set-variable name="deployment" value="@(context.Request.MatchedParameters.ContainsKey(&quot;deployment-id&quot;) ? context.Request.MatchedParameters[&quot;deployment-id&quot;] : &quot;claude-sonnet-55-kyc&quot;)" />
    <!-- choose: pick the limit by environment -->
    <choose>
      <!-- when: production traffic -->
      <when condition="@((string)context.Variables[&quot;environment&quot;] == &quot;prod&quot;)">
        <!-- llm-token-limit (production): keyed by subscription and deployment, so each use case has its own
             counter per model. Rate only: 1,000,000 tokens a minute is several times the busiest use case's normal peak and exists to stop
             runaway agent loops (429 with Retry-After). Counters are per gateway and not aggregated across
             regions, and concurrent requests can briefly exceed the limit (Microsoft Learn). -->
        <llm-token-limit counter-key="@(context.Subscription.Id + &quot;:&quot; + (string)context.Variables[&quot;deployment&quot;])" tokens-per-minute="1000000" estimate-prompt-tokens="false" remaining-tokens-variable-name="remainingTokens" tokens-consumed-variable-name="tokensConsumed" />
      </when>
      <!-- otherwise: development, test and sandbox traffic -->
      <otherwise>
        <!-- llm-token-limit (outside production): hard limits keyed the same way. 50,000 tokens a minute (429)
             and 20 million tokens a month per subscription and model (403 until the period resets; Monthly
             windows start at the UTC month). Prompt tokens are estimated so blocked calls never reach the
             model. -->
        <llm-token-limit counter-key="@(context.Subscription.Id + &quot;:&quot; + (string)context.Variables[&quot;deployment&quot;])" tokens-per-minute="50000" token-quota="20000000" token-quota-period="Monthly" estimate-prompt-tokens="true" remaining-quota-tokens-variable-name="remainingQuotaTokens" remaining-tokens-variable-name="remainingTokens" tokens-consumed-variable-name="tokensConsumed" />
      </otherwise>
    </choose>
    <!-- llm-emit-token-metric: sends prompt, completion and total token counts (cached tokens in preview) to
         Application Insights in the ai-spend-ledger namespace. Needs Application Insights integration with
         custom metrics enabled. Four custom dimensions (the limit is five per policy). Subscription ID is not
         added because the three labels already identify the subscription, and fewer dimensions keep the
         product of unique values well under the 1,000 active time series API Management tracks per namespace
         (beyond that, data is silently discarded). For OpenAI streaming calls set include_usage to true, or
         counts can be missing. -->
    <llm-emit-token-metric namespace="ai-spend-ledger">
      <!-- dimension: owning team, from the subscription name -->
      <dimension name="team" value="@((string)context.Variables[&quot;team&quot;])" />
      <!-- dimension: use case, the unit the ledger reports cost per successful outcome for -->
      <dimension name="use-case" value="@((string)context.Variables[&quot;useCase&quot;])" />
      <!-- dimension: prod or nonprod, so production and experiments are never mixed in one figure -->
      <dimension name="environment" value="@((string)context.Variables[&quot;environment&quot;])" />
      <!-- dimension: model deployment, the key the ledger matches to the billed line -->
      <dimension name="deployment" value="@((string)context.Variables[&quot;deployment&quot;])" />
    </llm-emit-token-metric>
  </inbound>
  <!-- backend: forward to the model; nothing extra here -->
  <backend>
    <!-- base: the API's backend settings (Azure OpenAI deployment or the Claude endpoint) -->
    <base />
  </backend>

    </set-header>
  </outbound>
  <!-- on-error: runs if any step fails, including a 429 or 403 from the token limit -->
  <on-error>
    <!-- base: inherited error handling and logging -->
    <base />
  </on-error>

azure/kql/soft-quota-alert.kql: the production soft quota as a scheduled query alert
// soft-quota-alert.kql: the production "soft quota". Production calls are never blocked by a monthly
// quota (llm-token-limit would answer 403); instead this query runs as an Azure Monitor scheduled query
// alert every hour and returns a row for each production use case and deployment past 80% or 100% of its
// monthly token allowance. Outside production the gateway enforces the hard quota itself.
//
// Assumed names: AppMetrics and the dimensions in tokens-by-team.kql. Allowances are illustrative and
// would be set from each owner's budget (budget / blended cost per 1M tokens), reviewed monthly.
let monthStart = startofmonth(now());
let allowance = datatable(useCase: string, deployment: string, monthlyTokens: long) [
    "support-assistant", "gpt54mini-shared", 3000000000,
    "support-assistant", "gpt-support-hard", 900000000,
    "knowledge-assistant", "gpt54mini-shared", 900000000,
    "fraud-explain", "gpt54nano-fraud", 12000000000,
    "kyc-review", "claude-sonnet-55-kyc", 3000000000
];
AppMetrics
| where TimeGenerated >= monthStart and Name == "Total Tokens"
| extend environment = tostring(Properties["environment"]), useCase = tostring(Properties["use-case"]),
         deployment = tostring(Properties["deployment"])
| where environment == "prod"
| summarize usedTokens = sum(Sum) by useCase, deployment
| join kind=inner allowance on useCase, deployment
| extend usedShare = usedTokens / todouble(monthlyTokens)
| extend level = case(usedShare >= 1.0, "100% of allowance", usedShare >= 0.8, "80% of allowance", "")
| where isnotempty(level)
| project useCase, deployment, usedTokens, monthlyTokens, usedShare, level

The commitment call

Illustrative Commit only to what the data says is steady S3 S8.

  • Baseline: 92 days of daily cost, past the 60 to 90 days the Foundation asks for before committing.
  • Commit to the floor, not the mean, at discounted rates. Production compute (AKS and VMs, after the rightsizing lever) never fell below $711 a day at pay-as-you-go rates ($29.61 an hour), against a mean of $848. A savings plan commits a discounted hourly amount, so the commitment is $29.61 × (1 − d), where d is the discount Microsoft's savings plan recommendation gives for this SKU mix; it is not in this pack's sources, so it is a parameter in org.json, not a number here. Microsoft's own order is rightsize first, then reservations for stable workloads, then savings plans.
  • No PTU yet. Daily production tokens swing 2.3× between the quietest and busiest day (P90 1.1× the median), and KYC document review runs moved 38% in a month. Provisioned throughput pays only when it is busy; sizing it needs the Foundry capacity calculator, so it is not priced here.

ledger/normalise.js: export column names to current FOCUS names, meter names to token columns, gateway metrics to estimate rows
// normalise.js: turn the three raw feeds into one FOCUS-aligned shape.
//
// 1. The cost export arrives with FOCUS 1.2 column names (Azure documents its FOCUS export up to
//    1.2-preview). The ledger works in FOCUS 1.4 names: ProviderName and PublisherName were removed
//    in 1.4; ServiceProviderName and HostProviderName (added in 1.3) carry the same facts.
// 2. Token lines get extension columns shaped like the draft FOCUS 1.5 additions (planned for
//    ratification on 3 Dec 2026, so they stay x_ columns for now): x_TokenDirection (Input, Output),
//    x_TokenCacheAction (Uncached, Read, Write), x_ModelDeveloper, x_ModelId.
// 3. Gateway metrics become FOCUS-aligned estimate rows: tokens times the published list price.
//    These rows are never added to the bill. They decide shares of billed lines and feed the
//    reconciliation only.
import { num } from './csv.js';
import { monthOf } from './dates.js';

export const RENAMES_1_2_TO_1_4 = { ProviderName: 'HostProviderName', PublisherName: 'ServiceProviderName' };
const NUMERIC = ['ConsumedQuantity', 'PricingQuantity', 'ListUnitPrice', 'ListCost', 'ContractedCost', 'BilledCost', 'EffectiveCost'];

// Azure OpenAI meter names follow the pattern "<model> [cached ]Input|Output global Tokens".
const METER = /^(gpt [\d.]+(?: mini| nano)?|text embedding)\s+(cached\s+)?(Input|Output)\s+global\s+Tokens$/i;
const MODEL_FROM_METER = { 'gpt 5.4': 'gpt-5.4', 'gpt 5.4 mini': 'gpt-5.4-mini', 'gpt 5.4 nano': 'gpt-5.4-nano', 'gpt 5.2': 'gpt-5.2', 'text embedding': 'text-embedding' };

export function parseMeter(meter) {
  const m = METER.exec(String(meter || '').trim());
  if (!m) return null;
  const modelId = MODEL_FROM_METER[m[1].toLowerCase()] || m[1].toLowerCase().replace(/\s+/g, '-');
  return {
    modelId,
    direction: m[3][0].toUpperCase() + m[3].slice(1).toLowerCase(),
    cacheAction: m[2] ? 'Read' : 'Uncached',
  };
}

export function deploymentOf(resourceId) {
  const m = /\/deployments\/([^/]+)$/.exec(resourceId || '');
  return m ? m[1] : null;
}

// tokenClass names used by prices.json.
export function tokenClassOf(direction, cacheAction) {
  if (direction === 'Output') return 'output';
  if (cacheAction === 'Read') return 'cachedInput';
  if (cacheAction === 'Write') return 'cacheWrite';
  return 'input';
}

export function normaliseExport(rows) {
  return rows.map((r) => {
    const o = {};
    for (const [k, v] of Object.entries(r)) o[RENAMES_1_2_TO_1_4[k] || k] = v;
    for (const k of NUMERIC) o[k] = num(o[k]) ?? 0;
    o.Tags = typeof o.Tags === 'string' ? (o.Tags ? JSON.parse(o.Tags) : {}) : (o.Tags || {});
    o.x_Date = String(o.ChargePeriodStart).slice(0, 10);
    o.x_Month = monthOf(o.x_Date);
    o.x_Deployment = deploymentOf(o.ResourceId);
    const meter = o.ConsumedUnit === 'Tokens' ? parseMeter(o.SkuMeter) : null;
    if (meter) {
      o.x_ModelId = meter.modelId;
      o.x_ModelDeveloper = meter.modelId.startsWith('gpt') || meter.modelId === 'text-embedding' ? 'OpenAI' : null;
      o.x_TokenDirection = meter.direction;
      o.x_TokenCacheAction = meter.cacheAction;
    }
    return o;
  });
}

// Price in effect for a model and token class on a date (latest effectiveFrom on or before it).
export function priceOn(prices, model, tokenClass, date) {
  let best = null;
  for (const p of prices.rows) {
    if (p.model !== model || p.tokenClass !== tokenClass) continue;
    if (p.effectiveFrom > date) continue;
    if (!best || p.effectiveFrom > best.effectiveFrom) best = p;
  }
  return best;
}

// One gateway metric row (a day, a team, a use case, a deployment) becomes up to four estimate rows,
// one per token class. Uncached input = input - cached - cache writes.
export function gatewayRows(metrics, prices) {
  const out = [];
  for (const m of metrics) {
    const input = num(m.input_tokens) || 0;
    const cached = num(m.cached_input_tokens) || 0;
    const write = num(m.cache_write_tokens) || 0;
    const output = num(m.output_tokens) || 0;
    const parts = [
      ['Input', 'Uncached', 'input', input - cached - write],
      ['Input', 'Read', 'cachedInput', cached],
      ['Input', 'Write', 'cacheWrite', write],
      ['Output', 'Uncached', 'output', output],
    ];
    for (const [direction, cacheAction, cls, qty] of parts) {
      if (!qty) continue;
      const p = priceOn(prices, m.model, cls, m.date);
      const model = prices.models[m.model];
      out.push({
        ChargePeriodStart: m.date + 'T00:00:00Z',
        x_Date: m.date,
        x_Month: monthOf(m.date),
        ServiceCategory: 'AI and Machine Learning',
        ConsumedQuantity: qty,
        ConsumedUnit: 'Tokens',
        x_TokenDirection: direction,
        x_TokenCacheAction: cacheAction,
        x_TokenClass: cls,
        x_ModelId: m.model,
        x_ModelDeveloper: model ? model.developer : null,
        x_Deployment: m.deployment,
        x_Team: m.team,
        x_UseCase: m.use_case,
        x_Environment: m.environment,
        x_ApimSubscription: m.apim_subscription,
        ListUnitPrice: p ? p.usdPerMTok : null,
        ListCost: p ? (qty / 1e6) * p.usdPerMTok : null,
        x_PriceSource: p ? p.src : null,
      });
    }
  }
  return out;
}

// Requests per use case and deployment per day, from the raw metrics (one count per metric row).
export function requestIndex(metrics) {
  const idx = {};
  for (const m of metrics) {
    const key = m.date + '|' + m.deployment;
    idx[key] ??= {};
    idx[key][m.use_case] = (idx[key][m.use_case] || 0) + (num(m.requests) || 0);
  }
  return idx;
}
ledger/allocate.js: the allocation rules, first match wins, every dollar once
// allocate.js: give every billed dollar an owner, or leave it visibly unallocated.
//
// The invoice is the source of truth: only BilledCost and EffectiveCost from the cost export are
// allocated. Gateway metrics never add cost; they only decide each team's share of a billed line.
// Rules, first match wins, each recorded in AllocatedMethodId (a FOCUS 1.3+ column):
//   gateway-token-share   an Azure OpenAI line the gateway metered that day: split by tokens of the
//                         same deployment and token class
//   gateway-cost-share    the aggregated Claude CCU line: split by each team's list-price estimate,
//                         because one CCU line mixes input, cache and output tokens
//   retrieval-call-share  the shared AI platform pool (AI Search): split by retrieval calls
//   resource-tag          the resource's own owner tag
//   inherited-tag         the resource group's or subscription's owner tag (resource tag wins, as
//                         in Azure tag inheritance by default)
//   unallocated           no rule applies; kept as its own line, never spread
import { tokenClassOf } from './normalise.js';

const sum = (a) => a.reduce((s, x) => s + x, 0);

function indexGateway(gw) {
  const byLine = {};    // date|deployment|class -> { team|useCase: qty }
  const byModel = {};   // date|model -> { team|useCase: list cost }
  for (const g of gw) {
    const k = g.x_Date + '|' + g.x_Deployment + '|' + g.x_TokenClass;
    byLine[k] ??= {};
    const who = g.x_Team + '|' + g.x_UseCase;
    byLine[k][who] = (byLine[k][who] || 0) + g.ConsumedQuantity;
    const mk = g.x_Date + '|' + g.x_ModelId;
    byModel[mk] ??= {};
    byModel[mk][who] = (byModel[mk][who] || 0) + (g.ListCost || 0);
  }
  return { byLine, byModel };
}

export function ownerFromTags(row, org) {
  const key = org.allocation.ownerTag;
  if (row.Tags && row.Tags[key]) return { owner: row.Tags[key], method: 'resource-tag' };
  const rg = org.allocation.resourceGroupTags[row.x_ResourceGroupName] || {};
  if (rg[key]) return { owner: rg[key], method: 'inherited-tag' };
  const sub = org.allocation.subscriptionTags[row.SubAccountId] || {};
  if (sub[key]) return { owner: sub[key], method: 'inherited-tag' };
  return { owner: 'unallocated', method: 'unallocated' };
}

function weightsFor(row, ctx) {
  const { org, gw, requests } = ctx;
  if (row.x_TokenDirection && row.x_Deployment) {
    const cls = tokenClassOf(row.x_TokenDirection, row.x_TokenCacheAction);
    const w = gw.byLine[row.x_Date + '|' + row.x_Deployment + '|' + cls];
    if (w && sum(Object.values(w)) > 0) return { method: 'gateway-token-share', weights: w };
  }
  const ccu = org.gateway.ccuLines[row.ResourceId];
  if (ccu) {
    const w = {};
    for (const model of ccu.models) {
      for (const [who, v] of Object.entries(gw.byModel[row.x_Date + '|' + model] || {})) w[who] = (w[who] || 0) + v;
    }
    if (sum(Object.values(w)) > 0) return { method: 'gateway-cost-share', weights: w };
  }
  const pool = row.Tags && row.Tags[org.allocation.poolTag];
  if (pool && org.allocation.pools[pool]) {
    const calls = requests[row.x_Date + '|' + org.gateway.retrievalDeployment] || {};
    const w = {};
    for (const [uc, n] of Object.entries(calls)) w[org.useCases[uc].owner + '|' + uc] = n;
    if (sum(Object.values(w)) > 0) return { method: 'retrieval-call-share', weights: w };
  }
  return null;
}

export function allocate(billed, gatewayRowsList, requests, org) {
  const ctx = { org, gw: indexGateway(gatewayRowsList), requests };
  const rows = [];
  billed.forEach((row, i) => {
    const base = {
      x_Date: row.x_Date, x_Month: row.x_Month, ServiceCategory: row.ServiceCategory, ServiceName: row.ServiceName,
      SubAccountId: row.SubAccountId, x_ResourceGroupName: row.x_ResourceGroupName, ResourceId: row.ResourceId,
      ResourceName: row.ResourceName, x_Deployment: row.x_Deployment, x_ModelId: row.x_ModelId || null,
      x_TokenDirection: row.x_TokenDirection || null, x_TokenCacheAction: row.x_TokenCacheAction || null,
      ConsumedUnit: row.ConsumedUnit, AllocatedResourceId: row.ResourceId, x_SourceRow: i,
    };
    const split = weightsFor(row, ctx);
    if (split) {
      const total = sum(Object.values(split.weights));
      for (const [who, w] of Object.entries(split.weights)) {
        const share = w / total;
        const [owner, useCase] = who.split('|');
        rows.push({ ...base, x_Owner: owner, x_UseCase: useCase, AllocatedMethodId: split.method, AllocatedTags: { owner, 'use-case': useCase },
          x_Share: share, ConsumedQuantity: row.ConsumedQuantity * share, ListCost: row.ListCost * share,
          BilledCost: row.BilledCost * share, EffectiveCost: row.EffectiveCost * share });
      }
    } else {
      const t = ownerFromTags(row, org);
      rows.push({ ...base, x_Owner: t.owner, x_UseCase: (row.Tags && row.Tags['use-case']) || null, AllocatedMethodId: t.method,
        AllocatedTags: { owner: t.owner }, x_Share: 1, ConsumedQuantity: row.ConsumedQuantity, ListCost: row.ListCost,
        BilledCost: row.BilledCost, EffectiveCost: row.EffectiveCost });
    }
  });
  return rows;
}

    byMethod[r.AllocatedMethodId] = (byMethod[r.AllocatedMethodId] || 0) + r.EffectiveCost;
  }
  const allocatedTotal = sum(Object.values(byOwner));
  const unallocated = byOwner.unallocated || 0;
  const owned = allocatedTotal - unallocated;
  const pct = allocatedTotal ? owned / allocatedTotal : 0;
  const t = org.allocation.targets;
  const stage = pct > t.run ? 'Run' : pct >= t.walk ? 'Walk' : pct >= t.crawl ? 'Crawl' : 'below Crawl';
  const unallocatedGroups = {};
  for (const r of inMonth.filter((x) => x.x_Owner === 'unallocated')) unallocatedGroups[r.x_ResourceGroupName] = (unallocatedGroups[r.x_ResourceGroupName] || 0) + r.EffectiveCost;
  return { month, billedTotal, allocatedTotal, byOwner, byMethod, unallocated, owned, ownedPct: pct, stage, targets: t, unallocatedGroups };
}
ledger/reconcile.js: estimate against the bill, gap explained, coverage and bypass
// reconcile.js: the list-price estimate against the bill, line by line, with the gap explained.
//
// The estimate is metered tokens times published list prices. It is never the number we allocate;
// it is the check that the gateway sees what the invoice charges for. For each billed AI line:
//   gap = billed - estimate = (unmetered usage at list price) - (negotiated discount) + residual
// unmetered usage is billed tokens the gateway never saw, priced class by class from the bill's
// quantities; the discount is ListCost - BilledCost; the residual is what is left, and it is only
// non-zero when the bill's unit price disagrees with the price sheet (a stale price row).
// The Claude CCU line carries no token counts, so its whole gap shows as unmetered or rate difference.
// Coverage is the share of token-billed AI cost explained by gateway metering (coverageOfAllAi
// restates it over all AI spend, including the AI Search tier, which is not token-billed); a bypass is a billed line
// with no metered calls at all.
import { tokenClassOf, priceOn } from './normalise.js';

const BYPASS_FLOOR = 1;          // dollars: ignore rounding-size lines
const PARTIAL_BELOW = 0.98;      // coverage below this is flagged as partial

export function reconcile(billed, gw, prices, org, month) {
  const lines = billed.filter((r) => r.x_Month === month && r.ServiceCategory === 'AI and Machine Learning'
    && (r.ConsumedUnit === 'Tokens' || org.gateway.ccuLines[r.ResourceId]));
  const groups = {};
  const priceMismatches = [];
  for (const r of lines) {
    const ccu = org.gateway.ccuLines[r.ResourceId];
    const key = ccu ? r.ResourceId : r.x_Deployment;
    const g = groups[key] ??= { key, label: ccu ? 'Claude (CCU line)' : r.x_Deployment, kind: ccu ? 'ccu' : 'tokens', subscription: r.SubAccountId,
      models: new Set(), billed: 0, list: 0, billedQty: {}, unitPrice: {} };
    g.billed += r.BilledCost;
    g.list += r.ListCost;
    if (!ccu) {
      g.models.add(r.x_ModelId);
      const cls = tokenClassOf(r.x_TokenDirection, r.x_TokenCacheAction);
      const k = r.x_Date + '|' + cls;
      g.billedQty[k] = (g.billedQty[k] || 0) + r.ConsumedQuantity;
      g.unitPrice[k] = r.ListUnitPrice;
      const p = priceOn(prices, r.x_ModelId, cls, r.x_Date);
      if (p && Math.abs(p.usdPerMTok - r.ListUnitPrice) > 1e-9) priceMismatches.push({ date: r.x_Date, deployment: r.x_Deployment, model: r.x_ModelId, cls, bill: r.ListUnitPrice, sheet: p.usdPerMTok });
    }
  }
  const gwMonth = gw.filter((g) => g.x_Month === month);
  const out = [];
  for (const g of Object.values(groups)) {
    let metered = [];
    if (g.kind === 'ccu') {
      const models = org.gateway.ccuLines[g.key].models;
      metered = gwMonth.filter((x) => models.includes(x.x_ModelId));
    } else {
      metered = gwMonth.filter((x) => x.x_Deployment === g.key);
    }
    const meteredQty = {};
    for (const x of metered) { const k = x.x_Date + '|' + x.x_TokenClass; meteredQty[k] = (meteredQty[k] || 0) + x.ConsumedQuantity; }
    const priced = metered.every((x) => x.ListCost !== null);
    const estimate = metered.length && priced ? metered.reduce((s, x) => s + x.ListCost, 0) : (metered.length ? null : 0);
    const discount = g.list - g.billed;
    let unmetered = 0;
    let residual = 0;
    let coverage;
    if (g.kind === 'ccu') {
      unmetered = g.billed - (estimate || 0);
      coverage = g.billed ? Math.min(1, (estimate || 0) / g.billed) : 0;
    } else {
      let billedTok = 0;
      let meteredTok = 0;
      for (const [k, q] of Object.entries(g.billedQty)) {
        const m = meteredQty[k] || 0;
        billedTok += q;
        meteredTok += Math.min(m, q);
        unmetered += ((q - m) / 1e6) * g.unitPrice[k];
      }
      coverage = billedTok ? meteredTok / billedTok : 0;
      residual = estimate === null ? 0 : (g.list - estimate) - unmetered;
    }
    const status = metered.length === 0 && g.billed > BYPASS_FLOOR ? 'bypass' : coverage < PARTIAL_BELOW ? 'partial' : 'covered';
    out.push({ key: g.key, label: g.label, kind: g.kind, subscription: g.subscription, models: [...g.models],
      billed: g.billed, list: g.list, discount, estimate, unmetered, residual, coverage, status });
  }
  out.sort((a, b) => b.billed - a.billed);
  const totBilled = out.reduce((s, x) => s + x.billed, 0);
  const pricedRows = out.filter((x) => x.estimate !== null);
  const totals = {
    billed: totBilled,
    list: out.reduce((s, x) => s + x.list, 0),
    estimate: pricedRows.reduce((s, x) => s + x.estimate, 0),
    discount: pricedRows.reduce((s, x) => s + x.discount, 0),
    unmetered: pricedRows.reduce((s, x) => s + x.unmetered, 0),
    residual: pricedRows.reduce((s, x) => s + x.residual, 0),
    unpricedBilled: out.filter((x) => x.estimate === null).reduce((s, x) => s + x.billed, 0),
    coverage: totBilled ? out.reduce((s, x) => s + x.billed * x.coverage, 0) / totBilled : 0,
  };
  totals.gap = pricedRows.reduce((s, x) => s + x.billed, 0) - totals.estimate;
  const notTokenBilled = billed.filter((r) => r.x_Month === month && r.ServiceCategory === 'AI and Machine Learning' && r.ConsumedUnit !== 'Tokens' && !org.gateway.ccuLines[r.ResourceId]);
  totals.notTokenBilled = notTokenBilled.reduce((s, r) => s + r.BilledCost, 0);
  // The same explained cost as a share of all AI spend, including lines that are not token-billed.
  totals.coverageOfAllAi = (totBilled + totals.notTokenBilled) ? (totals.coverage * totBilled) / (totBilled + totals.notTokenBilled) : 0;
  return { month, lines: out, totals, bypass: out.filter((x) => x.status === 'bypass'), partial: out.filter((x) => x.status === 'partial'), priceMismatches };
}
ledger/metrics.js: cost per successful outcome, daily percentiles, cache hit rate and cache cost efficiency
// metrics.js: unit economics per use case and month.
//
// Cost per successful outcome = all allocated AI cost of the use case / runs that met the quality
// bar. Failed, retried and discarded runs are in the numerator because they were billed [S3].
// Two views of it: avoidable (the cost that stops if the use case stops: its model tokens and
// per-call embeddings) and fully loaded (adds its share of the fixed shared platform, the AI Search
// tier, which stays and is re-spread over the other users if this use case stops). Decisions use
// the avoidable view.
// Daily cost per outcome is reported as P50 and P90 across the days of the month (daily aggregates,
// so this is the spread of daily unit cost, not of individual runs).
// Cache hit rate = cache reads / (reads + writes + uncached input) [S4]. Cache cost efficiency =
// input cost avoided, net of any write premium, as a share of what the same input would cost with
// no caching. It goes negative when cache writes are not read back.
import { priceOn } from './normalise.js';
import { num } from './csv.js';

const sum = (a) => a.reduce((s, x) => s + x, 0);

// Linear interpolation between closest ranks (the usual spreadsheet PERCENTILE.INC).
export function percentile(values, p) {
  const v = values.filter((x) => Number.isFinite(x)).slice().sort((a, b) => a - b);
  if (!v.length) return null;
  if (v.length === 1) return v[0];
  const h = (v.length - 1) * p;
  const lo = Math.floor(h);
  const hi = Math.ceil(h);
  return v[lo] + (h - lo) * (v[hi] - v[lo]);
}

export function outcomeTotals(rows) {
  const t = { runs: 0, successful: 0, failed: 0, retried: 0, discarded: 0, reviewMinutes: 0 };
  for (const o of rows) {
    t.runs += num(o.runs) || 0;
    t.successful += num(o.successful) || 0;
    t.failed += num(o.failed) || 0;
    t.retried += num(o.retried) || 0;
    t.discarded += num(o.discarded) || 0;
    t.reviewMinutes += num(o.review_minutes) || 0;
  }
  return t;
}

export function costPerSuccess(cost, successful) { return successful > 0 ? cost / successful : null; }

// Share of cost spent on runs that did not succeed, assuming cost per run is even across outcomes.
export function failedShareOfCost(t) { return t.runs > 0 ? (t.failed + t.discarded) / t.runs : 0; }

export function cacheStats(gwRows, prices) {
  let cached = 0; let writes = 0; let uncached = 0; let actual = 0; let noCache = 0;
  for (const g of gwRows) {
    if (g.x_TokenDirection !== 'Input') continue;
    const base = priceOn(prices, g.x_ModelId, 'input', g.x_Date);
    if (!base) continue;
    const q = g.ConsumedQuantity;
    if (g.x_TokenCacheAction === 'Read') cached += q;
    else if (g.x_TokenCacheAction === 'Write') writes += q;
    else uncached += q;
    actual += g.ListCost || 0;
    noCache += (q / 1e6) * base.usdPerMTok;
  }
  const input = cached + writes + uncached;
  return {
    hitRate: input ? cached / input : 0,
    costEfficiency: noCache ? (noCache - actual) / noCache : 0,
    inputTokens: input, cachedTokens: cached, writeTokens: writes,
  };
}

export function unitEconomics({ allocated, gw, outcomes, prices, org, month }) {
  const out = {};
  for (const [uc, meta] of Object.entries(org.useCases)) {
    const rows = allocated.filter((r) => r.x_Month === month && r.x_UseCase === uc && r.ServiceCategory === 'AI and Machine Learning');
    const spend = sum(rows.map((r) => r.EffectiveCost));
    const fixedShared = sum(rows.filter((r) => r.AllocatedMethodId === 'retrieval-call-share').map((r) => r.EffectiveCost));
    const embeddings = sum(rows.filter((r) => r.x_ModelId === 'text-embedding').map((r) => r.EffectiveCost));
    const oc = outcomes.filter((o) => o.date.slice(0, 7) === month && o.use_case === uc);
    const t = outcomeTotals(oc);
    const g = gw.filter((x) => x.x_Month === month && x.x_UseCase === uc && x.x_ModelId !== 'text-embedding');
    const tokens = sum(g.map((x) => x.ConsumedQuantity));
    const daily = {};
    for (const r of rows) if (r.AllocatedMethodId !== 'retrieval-call-share') daily[r.x_Date] = (daily[r.x_Date] || 0) + r.EffectiveCost;
    const dailyCps = oc.filter((o) => num(o.successful) > 0).map((o) => ({ date: o.date, value: (daily[o.date] || 0) / num(o.successful) }));
    const cache = cacheStats(g, prices);
    const cps = costPerSuccess(spend, t.successful);
    const avoidable = spend - fixedShared;
    out[uc] = {
      useCase: uc, name: meta.name, owner: meta.owner, month,
      spend, avoidableSpend: avoidable, fixedSharedSpend: fixedShared, embeddingSpend: embeddings, tokenSpend: avoidable - embeddings,
      ...t,
      successRate: t.runs ? t.successful / t.runs : 0,
      costPerRun: t.runs ? avoidable / t.runs : null,
      costPerSuccess: cps,
      avoidableCostPerSuccess: costPerSuccess(avoidable, t.successful),
      p50: percentile(dailyCps.map((x) => x.value), 0.5),
      p90: percentile(dailyCps.map((x) => x.value), 0.9),
      dailyCostPerSuccess: dailyCps,
      failedShareOfCost: failedShareOfCost(t),
      failedCost: avoidable * failedShareOfCost(t),
      cacheHitRate: cache.hitRate,
      cacheCostEfficiency: cache.costEfficiency,
      tokens,
      tokensPerSuccess: t.successful ? tokens / t.successful : null,
      costPerMTok: tokens ? ((avoidable - embeddings) / tokens) * 1e6 : null,
      reviewMinutesPerSuccess: t.successful ? t.reviewMinutes / t.successful : null,
    };
  }
  return out;
}

ledger/budget.js: baseline, budget, driver-based forecast, alerts, variance split
// budget.js: budgets, forecasts, alerts and the month-on-month variance split.
//
// Baseline = mean of the two prior months. Budget = baseline x 1.15, inside the 110 to 120% band [S3].
// Alerts at 80% and 100% of budget on actual cost, and at 100% on forecast [S3]. Azure evaluates
// budgets about once a day [S8], so an alert is raised the day after the data crosses the line.
// Forecast from drivers: expected runs for each remaining day (trailing 14 days, same day type,
// weekday or weekend) x cost per run (trailing 7 days), plus a run rate for cost that no use case
// drives. A trailing-mean forecast (month to date / days elapsed x days in month) is kept only as a
// cross-check.
// Variance, September to October, for each use case's avoidable cost (model tokens and embeddings):
//   volume = change in runs x September cost per run
//   price  = October tokens x change in published list price (zero unless a price row changes)
//   mix    = the rest: tokens per run, model mix and success rates
// plus two buckets that runs do not drive, kept apart: the fixed shared platform (the AI Search
// tier, allocated by retrieval calls) and unattributed AI cost (billed AI with no use case).
import { datesOfMonth, prevMonth, isWeekend, addDays } from './dates.js';
import { priceOn } from './normalise.js';
import { num } from './csv.js';

const sum = (a) => a.reduce((s, x) => s + x, 0);

}

export function budgetOf(baseline, multiple) { return baseline === null ? null : baseline * multiple; }

    }

function window(endDate, days) { const out = []; for (let k = days - 1; k >= 0; k--) out.push(addDays(endDate, -k)); return out; }

// Month-end forecast with data through asOf (inclusive).
export function driverForecast(series, month, asOf, cfg) {
  const days = datesOfMonth(month);
  const mtd = sum(days.filter((d) => d <= asOf).map((d) => series.total[d] || 0));
  const remaining = days.filter((d) => d > asOf);
  const unitWin = window(asOf, cfg.trailingDaysForUnitCost);
  const volWin = window(asOf, cfg.trailingDaysForVolume);
  let driven = 0;
  let drivenToday = 0;
  for (const uc of Object.keys(series.byUc)) {
    const cost = sum(unitWin.map((d) => series.byUc[uc][d] || 0));
    const runs = sum(unitWin.map((d) => (series.runs[uc] || {})[d] || 0));
    const cpr = runs ? cost / runs : 0;
    const mean = (pred) => { const ds = volWin.filter(pred); return ds.length ? sum(ds.map((d) => (series.runs[uc] || {})[d] || 0)) / ds.length : 0; };
    const we = mean((d) => isWeekend(d)) || mean(() => true);
    const wd = mean((d) => !isWeekend(d)) || mean(() => true);
    for (const d of remaining) driven += (isWeekend(d) ? we : wd) * cpr;
    drivenToday += cost;
  }
  const totalWin = sum(unitWin.map((d) => series.total[d] || 0));
  const otherPerDay = Math.max(0, totalWin - drivenToday) / unitWin.length;
  return mtd + driven + otherPerDay * remaining.length;
}

export function trailingMeanForecast(series, month, asOf) {
  const days = datesOfMonth(month);
  const done = days.filter((d) => d <= asOf);
  const mtd = sum(done.map((d) => series.total[d] || 0));
  return done.length ? (mtd / done.length) * days.length : 0;
}

export function evaluateBudget(series, month, budget, cfg) {
  const days = datesOfMonth(month);
  let mtd = 0;
  const path = days.map((d) => {
    mtd += series.total[d] || 0;
    return { date: d, actualToDate: mtd, forecast: driverForecast(series, month, d, cfg), trailingMean: trailingMeanForecast(series, month, d) };
  });
  const alerts = [];
  if (budget) {
    for (const t of cfg.thresholds) {
      const hit = path.find((p) => p.actualToDate >= t * budget);
      alerts.push({ type: 'actual', threshold: t, crossedOn: hit ? hit.date : null, raisedOn: hit ? addDays(hit.date, cfg.dataLagDays) : null });
    }
    const f = path.find((p) => p.forecast >= cfg.forecastThreshold * budget);
    alerts.push({ type: 'forecast', threshold: cfg.forecastThreshold, crossedOn: f ? f.date : null, raisedOn: f ? addDays(f.date, cfg.dataLagDays) : null });
  }
  const last = path[path.length - 1];
  return { month, budget, actual: last.actualToDate, pctOfBudget: budget ? last.actualToDate / budget : null, path, alerts };
}

// The month-on-month variance split for AI cost.
export function variance({ allocated, gw, outcomes, prices, org, month }) {
  const prev = prevMonth(month, 1);
  const isToken = (r) => r.ServiceCategory === 'AI and Machine Learning' && r.AllocatedMethodId !== 'retrieval-call-share'
    && (r.ConsumedUnit === 'Tokens' || org.gateway.ccuLines[r.ResourceId]);
  const isFixed = (r) => r.ServiceCategory === 'AI and Machine Learning' && r.AllocatedMethodId === 'retrieval-call-share';
  const isAi = (r) => r.ServiceCategory === 'AI and Machine Learning';
  const cost = (m, pred) => sum(allocated.filter((r) => r.x_Month === m && pred(r)).map((r) => r.EffectiveCost));
  const runs = (m, uc) => sum(outcomes.filter((o) => o.date.slice(0, 7) === m && o.use_case === uc).map((o) => num(o.runs) || 0));
  // The model each deployment ran on the last day of the previous month: the reference price.
  const refModel = {};
  for (const r of allocated) if (r.x_Month === prev && r.x_Deployment && r.x_ModelId) refModel[r.x_Deployment] = r.x_ModelId;
  const refDate = datesOfMonth(prev).slice(-1)[0];
  const rows = [];
  for (const uc of Object.keys(org.useCases)) {
    const pred = (r) => r.x_UseCase === uc && isToken(r);
    const cPrev = cost(prev, pred); const cNow = cost(month, pred);
    const rPrev = runs(prev, uc); const rNow = runs(month, uc);
    const volume = rPrev ? (rNow - rPrev) * (cPrev / rPrev) : 0;
    let price = 0;
    for (const r of allocated) {
      if (r.x_Month !== month || !pred(r) || !r.x_ModelId || r.ConsumedUnit !== 'Tokens') continue;
      const cls = r.x_TokenDirection === 'Output' ? 'output' : r.x_TokenCacheAction === 'Read' ? 'cachedInput' : 'input';
      const now = priceOn(prices, r.x_ModelId, cls, r.x_Date);
      const ref = priceOn(prices, refModel[r.x_Deployment] || r.x_ModelId, cls, refDate);
      if (!now || !ref || !r.ListCost) continue;
      const netFactor = r.EffectiveCost / r.ListCost;
      price += (r.ConsumedQuantity / 1e6) * (now.usdPerMTok - ref.usdPerMTok) * netFactor;
    }
    // CCU-billed models: price effect from the gateway estimate rows (list prices per token class).
    for (const g of gw) {
      if (g.x_Month !== month || g.x_UseCase !== uc) continue;
      if (!Object.values(org.gateway.ccuLines).some((c) => c.models.includes(g.x_ModelId))) continue;
      const now = priceOn(prices, g.x_ModelId, g.x_TokenClass, g.x_Date);
      const ref = priceOn(prices, g.x_ModelId, g.x_TokenClass, refDate);
      if (now && ref) price += (g.ConsumedQuantity / 1e6) * (now.usdPerMTok - ref.usdPerMTok);
    }
    const change = cNow - cPrev;
    rows.push({ useCase: uc, previous: cPrev, current: cNow, change, volume, price, mix: change - volume - price, runsPrevious: rPrev, runsCurrent: rNow });
  }
  const aiPrev = cost(prev, isAi); const aiNow = cost(month, isAi);
  const tokenChange = sum(rows.map((r) => r.change));
  const fixedPrev = cost(prev, isFixed); const fixedNow = cost(month, isFixed);
  const fixedPlatform = fixedNow - fixedPrev;
  const unattributed = (aiNow - aiPrev) - tokenChange - fixedPlatform;
  const platform = fixedPlatform + unattributed;
  // What sits in the two buckets, by resource: fixed shared platform, and unattributed AI cost.
  const ucs = Object.keys(org.useCases);
  const other = {};
  for (const r of allocated) {
    if (!isAi(r) || (r.x_UseCase && ucs.includes(r.x_UseCase) && isToken(r))) continue;
    if (r.x_Month !== prev && r.x_Month !== month) continue;
    const o = other[r.ResourceName] ??= { resource: r.ResourceName, kind: isFixed(r) ? 'fixed' : 'unattributed', previous: 0, current: 0 };
    o[r.x_Month === prev ? 'previous' : 'current'] += r.EffectiveCost;
  }
  const otherByResource = Object.values(other).map((o) => ({ ...o, change: o.current - o.previous })).sort((a, b) => Math.abs(b.change) - Math.abs(a.change));
  return {
    month, previousMonth: prev, previous: aiPrev, current: aiNow, change: aiNow - aiPrev, rows,
    volume: sum(rows.map((r) => r.volume)), price: sum(rows.map((r) => r.price)), mix: sum(rows.map((r) => r.mix)), platform, otherByResource,
    fixedPlatform, unattributed, fixedPrevious: fixedPrev, fixedCurrent: fixedNow,
    unattributedPrevious: aiPrev - fixedPrev - sum(rows.map((r) => r.previous)), unattributedCurrent: aiNow - fixedNow - sum(rows.map((r) => r.current)),
  };
}
ledger/levers.js: levers in sequence on the remaining base, grades, next-bill checks
// levers.js: the optimisation pipeline, priced from the ledger.
//
// Each lever has an eligible cost (what it can touch), an effect (the share of that cost it
// removes), a method and an evidence grade:
//   measured           arithmetic on measured quantities only
//   assumption-based   price-sheet arithmetic on an assumed share or rate (the assumption is shown)
//   Foundation prior   the low end of a FinOps Foundation range [S3], until a test measures it
// Within a use case the levers run in order, each on the cost left by the ones before it, so the
// pipeline never adds independent percentages. A saving can never exceed its eligible cost, and the
// eligible cost can never exceed what remains. The next-bill check is on unit cost (cost per
// successful outcome), not the total bill, because volume moves the total for other reasons.
// A lever can be marked validated or realised only when its evidence is measured; anything priced
// on an assumption or a Foundation prior stays identified until a test measures it.
import { priceOn } from './normalise.js';
import { datesOfMonth, prevMonth } from './dates.js';
import { num } from './csv.js';

const sum = (a) => a.reduce((s, x) => s + x, 0);
const clamp01 = (x) => Math.max(0, Math.min(1, x));

// Automatic prompt caching: raising the hit rate from h to target, where cached input bills at
// (1 - disc) of the input price, saves this share of input cost.
export function cacheLeverEffect(h, target, disc) {
  const a = clamp01(h); const b = Math.max(a, clamp01(target)); const d = clamp01(disc);
  return 1 - d * a > 0 ? (d * (b - a)) / (1 - d * a) : 0;
}

export function gradeOf(lever) {
  const e = lever.effect.kind;
  const g = lever.eligible.kind;
  if (e === 'prior') return 'Foundation prior';
  if (e === 'none') return null;
  if ((e === 'measured' || e === 'price-sheet') && (g === 'measured')) return 'measured';
  return 'assumption-based';
}

// Apply one lever to the remaining components of a scope. Returns { eligible, saving }.
// remaining = { input, output, hard: { input, output } }, where hard is the part of input and output
// on the hard-case path (a subset). Components: 'input', 'output', 'all' or 'hard-path'.
export function applyStep(remaining, component, share, effect) {
  const s = clamp01(share);
  const f = clamp01(effect);
  remaining.hard ??= { input: 0, output: 0 };
  const cutFrom = (k, cut, onHard) => {
    const before = remaining[k];
    remaining[k] = Math.max(0, before - cut);
    if (onHard) remaining.hard[k] = Math.max(0, remaining.hard[k] - cut);
    else if (before > 0) remaining.hard[k] *= remaining[k] / before;   // the hard path shrinks in proportion
  };
  let eligible = 0;
  if (component === 'input' || component === 'output') {
    eligible = remaining[component] * s;
    cutFrom(component, eligible * f, false);
  } else {
    const onHard = component === 'hard-path';
    const pool = onHard ? remaining.hard : remaining;
    const base = pool.input + pool.output;
    eligible = base * s;
    const ki = base ? pool.input / base : 0;
    const cut = eligible * f;
    cutFrom('input', cut * ki, onHard);
    cutFrom('output', cut * (1 - ki), onHard);
  }
  return { eligible, saving: eligible * f };
}

// Token cost components of a use case in a month: input and output, and the part on the hard path.
function components(allocated, uc, month, hardDeployment) {
  const rows = allocated.filter((r) => r.x_Month === month && r.x_UseCase === uc && r.ServiceCategory === 'AI and Machine Learning'
    && r.AllocatedMethodId !== 'retrieval-call-share' && r.x_ModelId !== 'text-embedding');
  const tokenRows = rows.filter((r) => r.x_TokenDirection);
  const ccuRows = rows.filter((r) => !r.x_TokenDirection);
  const c = { input: 0, output: 0, hard: { input: 0, output: 0 } };
  for (const r of tokenRows) {
    const k = r.x_TokenDirection === 'Output' ? 'output' : 'input';
    c[k] += r.EffectiveCost;
    if (r.x_Deployment === hardDeployment) c.hard[k] += r.EffectiveCost;
  }
  return { c, ccu: sum(ccuRows.map((r) => r.EffectiveCost)) };
}

// For a CCU-billed use case, split its billed cost into input and output by the gateway estimate.
function ccuSplit(gw, uc, month, total) {
  const g = gw.filter((x) => x.x_Month === month && x.x_UseCase === uc);
  const inp = sum(g.filter((x) => x.x_TokenDirection === 'Input').map((x) => x.ListCost || 0));
  const out = sum(g.filter((x) => x.x_TokenDirection === 'Output').map((x) => x.ListCost || 0));
  const t = inp + out;
  return t ? { input: total * (inp / t), output: total * (out / t) } : { input: total, output: 0 };
}

// Prompt tokens per call for a use case in a month, from the gateway metrics (embeddings excluded).
export function promptTokensPerCall(metrics, uc, month) {
  const rows = metrics.filter((m) => m.use_case === uc && m.date.slice(0, 7) === month && m.model !== 'text-embedding');
  const calls = sum(rows.map((m) => num(m.requests) || 0));
  return calls ? sum(rows.map((m) => num(m.input_tokens) || 0)) / calls : 0;
}

export function priceLevers({ levers, allocated, billed, gw, metrics = [], outcomes, prices, org, ue, decisions, vmUtil, month }) {
  const out = [];
  const byUc = {};
  for (const l of levers.slice().sort((a, b) => (a.useCase || a.resource || '').localeCompare(b.useCase || b.resource || '') || a.order - b.order)) {
    const grade = gradeOf(l);
    const row = { id: l.id, name: l.name, useCase: l.useCase || null, resource: l.resource || null, group: l.group || (l.useCase ? 'use-case' : 'cloud'),
      owner: l.owner, status: statusFor(l, grade), statusInData: l.status,
      qualityGate: l.qualityGate, caution: l.caution || null, grade, eligibleText: l.eligible.text, effectText: l.effect.text,
      effectSrc: l.effect.src || null, range: l.effect.range || null, saving: null, eligibleCost: null, effect: null, method: '', check: null, waysRound: l.waysRound || null };
    if (l.useCase) {
      const u = ue[l.useCase];
      if (!byUc[l.useCase]) {
        const { c, ccu } = components(allocated, l.useCase, month, 'gpt-support-hard');
        if (ccu) { const s = ccuSplit(gw, l.useCase, month, ccu); c.input += s.input; c.output += s.output; }
        byUc[l.useCase] = { remaining: c, start: c.input + c.output, saved: 0 };
      }
      const scope = byUc[l.useCase];
      const decision = decisions && decisions[l.useCase] ? decisions[l.useCase].decision : null;
      if (l.onlyIfDecision && decision && !l.onlyIfDecision.includes(decision)) {
        row.status = 'on hold';
        row.method = `On hold: the use case is marked ${decision}.`;
        out.push(row); continue;
      }
      let share = 1; let effect = 0;
      if (l.type === 'blocked') {
        row.saving = 0; row.method = 'Blocked: ' + l.effect.text + '.';
        out.push(row); continue;
      } else if (l.type === 'routing' || l.type === 'prior' || l.type === 'batch') {
        share = l.eligible.value ?? 1;
        effect = l.effect.point ?? l.effect.value;
      } else if (l.type === 'cache-azure') {
        // The achievable hit rate is bounded by the stable prefix: only the tokens that are identical
        // on every call can be served from cache.
        const h = clamp01(u.cacheHitRate);
        const perCall = promptTokensPerCall(metrics, l.useCase, month);
        const target = Math.max(h, clamp01(perCall ? l.stablePrefixTokens / perCall : 0));
        row.promptTokensPerCall = perCall; row.stablePrefixTokens = l.stablePrefixTokens;
        const miniIn = priceOn(prices, 'gpt-5.4-mini', 'input', datesOfMonth(month).slice(-1)[0]);
        const miniCached = priceOn(prices, 'gpt-5.4-mini', 'cachedInput', datesOfMonth(month).slice(-1)[0]);
        const disc = 1 - miniCached.usdPerMTok / miniIn.usdPerMTok;    // 0.9 on the GPT-5.4 family
        effect = cacheLeverEffect(h, target, disc);
        row.measuredHitRate = h; row.targetHitRate = target; row.cacheDiscount = disc;
      } else if (l.type === 'failure') {
        const base = outcomes.filter((o) => o.use_case === l.useCase && (o.date.slice(0, 7) === prevMonth(month, 1) || o.date.slice(0, 7) === prevMonth(month, 2)));
        const now = outcomes.filter((o) => o.use_case === l.useCase && o.date.slice(0, 7) === month);
        const f = (rows) => { const r = sum(rows.map((o) => num(o.runs))); return r ? sum(rows.map((o) => num(o.failed))) / r : 0; };
        const excess = Math.max(0, f(now) - f(base));
        share = excess;                                // share of remaining cost spent on excess failures
        effect = l.effect.value;
        row.failureRateBaseline = f(base); row.failureRateNow = f(now);
      }
      const step = applyStep(scope.remaining, l.component, share, effect);
      scope.saved += step.saving;
      row.eligibleCost = step.eligible; row.saving = step.saving; row.effect = effect;
      const after = (u.avoidableSpend - scope.saved) / u.successful;
      row.check = { metric: 'avoidable cost per ' + org.useCases[l.useCase].outcomeNoun, current: u.avoidableCostPerSuccess, target: after };
      row.method = methodText(l, row);
    } else if (l.type === 'schedule') {
      const lines = billed.filter((r) => r.ResourceName === l.resource);
      const days = datesOfMonth(month);
      const before = lines.filter((r) => r.x_Month === prevMonth(month, 1));
      const meanBefore = before.length ? sum(before.map((r) => r.EffectiveCost)) / before.length : 0;
      const afterRows = lines.filter((r) => r.x_Date >= l.changedOn && r.x_Month === month);
      const meanAfter = afterRows.length ? sum(afterRows.map((r) => r.EffectiveCost)) / afterRows.length : meanBefore;
      row.eligibleCost = meanBefore * days.length;
      row.saving = Math.max(0, meanBefore - meanAfter) * days.length;
      row.effect = row.eligibleCost ? row.saving / row.eligibleCost : 0;
      row.realised = sum(afterRows.map((r) => Math.max(0, meanBefore - r.EffectiveCost)));
      row.expectedOffShare = l.hoursOffPerWeek / 168;
      row.check = { metric: 'non-production cluster cost per day', current: meanBefore, target: meanAfter };
      row.method = `Measured from the bill: mean daily cost ${fmt(meanBefore)} in ${monthLabel(prevMonth(month, 1))}, ${fmt(meanAfter)} from the change; ${Math.round(row.expectedOffShare * 100)}% of hours are scheduled off.`;
    } else if (l.type === 'rightsize') {
      const low = new Set(vmUtil.filter((v) => v.month === month && num(v.p95_cpu_pct) < l.cpuThresholdPct).map((v) => v.resource));
      const cost = sum(billed.filter((r) => r.x_Month === month && low.has(r.ResourceName)).map((r) => r.EffectiveCost));
      row.eligibleCost = cost; row.effect = l.effect.value; row.saving = cost * l.effect.value;
      row.resources = [...low];
      row.check = { metric: 'cost per VM-day', current: cost / Math.max(1, low.size) / datesOfMonth(month).length, target: (cost * (1 - l.effect.value)) / Math.max(1, low.size) / datesOfMonth(month).length };
      row.method = `Assumption-based: ${low.size} VMs (${[...low].join(', ')}) under ${l.cpuThresholdPct}% P95 CPU all month; ${l.effect.text}.`;
    } else if (l.type === 'unpriced') {
      row.saving = null;
      row.method = 'Not priced: ' + l.effect.text + '.';
    }
    out.push(row);
  }
  const counted = out.filter((r) => r.saving !== null && !['on hold', 'blocked'].includes(r.status));
  const by = (g) => sum(counted.filter((r) => r.grade === g).map((r) => r.saving));
  const totals = {
    measured: by('measured'),
    assumption: by('assumption-based'),
    prior: by('Foundation prior'),
  };
  totals.measuredAndAssumption = totals.measured + totals.assumption;
  totals.all = totals.measuredAndAssumption + totals.prior;
  totals.realised = sum(out.filter((r) => r.status === 'realised').map((r) => r.realised || 0));
  const scopes = Object.fromEntries(Object.entries(byUc).map(([k, v]) => [k, { start: v.start, saved: v.saved }]));
  return { levers: out, totals, scopes };
}

function methodText(l, row) {
  const pct = (x) => (Math.round(x * 1000) / 10).toString().replace(/\.0$/, '') + '%';
  if (l.type === 'cache-azure') {
    const n = (x) => Math.round(x).toLocaleString('en-GB');
    return `Assumption-based: hit rate ${pct(row.measuredHitRate)} measured; the stable ${n(row.stablePrefixTokens)}-token prefix is ${pct(row.targetHitRate)} of the average ${n(row.promptTokensPerCall)}-token prompt, so at most ${pct(row.targetHitRate)} of input can hit. Cached input at ${pct(1 - row.cacheDiscount)} of the input price then saves ${pct(row.effect)} of input cost.`;
  }
  if (l.type === 'failure') {
    return `Assumption-based: failure rate ${pct(row.failureRateNow)} against ${pct(row.failureRateBaseline)} in the two prior months (measured); ${l.effect.text}.`;
  }
  if (l.effect.kind === 'prior') {
    const share = l.eligible.value !== undefined ? `${pct(l.eligible.value)} of the path eligible (assumption); ` : '';
    return `Foundation prior: ${share}${pct(l.effect.range[0])} to ${pct(l.effect.range[1])} range, counted at ${pct(l.effect.point)}.`;
  }
  if (l.type === 'batch') return `Assumption-based: ${l.eligible.text}; ${l.effect.text}.`;
  return '';
}
ledger/decision.js and ledger/compare.js: scale, fix or stop; cost per task across providers
// decision.js: scale, fix or stop for each use case, from AVOIDABLE cost per successful outcome (the
// cost that stops if the use case stops; a fixed shared tier does not) against an illustrative value
// per outcome (data/value.json) and the owner's quality bar.
//   stop   value per outcome is at or below cost per outcome (value / cost <= stopBelowValueToCost)
//   fix    value is under scaleFromValueToCost times cost, or the success rate is below the bar
//   scale  otherwise
// The thresholds live in data/org.json so an owner can change them in one place.

export function valuePerOutcome(v) { return v.minutesSaved * v.loadedCostPerMinute; }

export function decide({ costPerSuccess, valuePerSuccess, successRate, qualityBar }, rules) {
  const reasons = [];
  if (costPerSuccess === null || costPerSuccess === undefined) return { decision: 'fix', ratio: null, reasons: ['no successful outcomes this month'] };
  const ratio = costPerSuccess > 0 ? valuePerSuccess / costPerSuccess : Infinity;
  if (ratio <= rules.stopBelowValueToCost) {
    reasons.push('cost per successful outcome is at or above its value');
    if (successRate < qualityBar) reasons.push('success rate is below the quality bar');
    return { decision: 'stop', ratio, reasons };
  }
  if (successRate < qualityBar) reasons.push('success rate is below the quality bar');
  if (ratio < rules.scaleFromValueToCost) reasons.push('value is less than three times cost');
  if (reasons.length) return { decision: 'fix', ratio, reasons };
  return { decision: 'scale', ratio, reasons: ['value well above cost and quality bar met'] };
}

export function decideAll(ue, values, org) {
  const out = {};
  for (const [uc, u] of Object.entries(ue)) {
    const v = values.useCases[uc];
    const value = valuePerOutcome(v);
    out[uc] = { useCase: uc, valuePerSuccess: value, assumption: v.assumption, qualityBar: v.qualityBar, qualityBarText: v.qualityBarText,
      basis: 'avoidable', avoidableCostPerSuccess: u.avoidableCostPerSuccess, loadedCostPerSuccess: u.costPerSuccess,
      ...decide({ costPerSuccess: u.avoidableCostPerSuccess, valuePerSuccess: value, successRate: u.successRate, qualityBar: v.qualityBar }, org.decision) };
  }
  return out;
}

  return (inputTokens / 1e6) * i.usdPerMTok + (outputTokens / 1e6) * o.usdPerMTok;
}

}

// whatif.js: the support assistant's cost per accepted draft, one workflow, at list prices.
//
// Steps: an optional triage call, then the draft. Most tickets use the draft model; a share of hard
// cases uses GPT-5.4. Every input is clamped to a sensible range, so the result is never negative,
// never infinite and never NaN: a failure rate is capped below 100%, shares sit between 0 and 1.
//   model cost per run   = triage + (1 - hard share) x draft(model) + hard share x draft(GPT-5.4),
//                          with batch at 50% off on the batched share [S11]
//   per accepted draft   = cost per run / (1 - failure rate); every attempt is paid for [S3]
//   review per accepted  = review minutes x loaded cost per minute / (1 - failure rate)

export const TRIAGE_TOKENS = { input: 2500, output: 60 };   // illustrative size of a triage call
export const HARD_MODEL = 'gpt-5.4';
export const WHATIF_SPEC = {
  triageModel: { options: ['none', 'gpt-5.4-nano', 'gpt-5.4-mini'], default: 'none' },
  draftModel: { options: ['gpt-5.4-mini', 'gpt-5.4-nano', 'gpt-5.4'], default: 'gpt-5.4-mini' },
  hardShare: { min: 0, max: 1, default: 0.15 },
  inputTokens: { min: 500, max: 100000, default: 16000 },
  outputTokens: { min: 50, max: 8000, default: 1000 },
  cacheHitRate: { min: 0, max: 0.9, default: 0.18 },
  batchShare: { min: 0, max: 1, default: 0 },
  failureRate: { min: 0, max: 0.6, default: 0.16 },
  reviewMinutes: { min: 0, max: 15, default: 1 },
  costPerMinute: { min: 0, max: 3, default: 0.8 },
  volume: { min: 0, max: 1000000, default: 150000 },
};

export function clampInputs(raw, defaults = {}) {
  const out = {};
  for (const [k, spec] of Object.entries(WHATIF_SPEC)) {
    const fallback = defaults[k] !== undefined ? defaults[k] : spec.default;
    const v = raw ? raw[k] : undefined;
    if (spec.options) {
      out[k] = spec.options.includes(v) ? v : (spec.options.includes(fallback) ? fallback : spec.default);
    } else {
      const n = typeof v === 'number' ? v : (v === '' || v === null || v === undefined ? NaN : Number(v));
      const base = Number.isFinite(n) ? n : Number(fallback);
      out[k] = Math.min(spec.max, Math.max(spec.min, Number.isFinite(base) ? base : spec.default));
    }
  }
  return out;
}

function callCost(prices, model, date, input, output, hit) {
  const pIn = priceOn(prices, model, 'input', date).usdPerMTok;
  const pCached = priceOn(prices, model, 'cachedInput', date).usdPerMTok;
  const pOut = priceOn(prices, model, 'output', date).usdPerMTok;
  return (input * ((1 - hit) * pIn + hit * pCached) + output * pOut) / 1e6;
}

export function whatIf(raw, prices, date, defaults) {
  const x = clampInputs(raw, defaults);
  const batch = prices.rules.batchMultiplier.value;
  const triage = x.triageModel === 'none' ? 0 : callCost(prices, x.triageModel, date, TRIAGE_TOKENS.input, TRIAGE_TOKENS.output, 0);
  const draft = callCost(prices, x.draftModel, date, x.inputTokens, x.outputTokens, x.cacheHitRate);
  const hard = callCost(prices, HARD_MODEL, date, x.inputTokens, x.outputTokens, x.cacheHitRate);
  const perRunList = triage + (1 - x.hardShare) * draft + x.hardShare * hard;
  const perRun = perRunList * (1 - x.batchShare * (1 - batch));
  const attempts = 1 / (1 - x.failureRate);
  const model = perRun * attempts;
  const review = x.reviewMinutes * x.costPerMinute * attempts;
  const total = model + review;
  return {
    inputs: x,
    perRun,
    attemptsPerSuccess: attempts,
    modelPerSuccess: model,
    reviewPerSuccess: review,
    totalPerSuccess: total,
    reviewShare: total > 0 ? review / total : 0,
    monthlyModel: model * x.volume,
    monthlyTotal: total * x.volume,
  };
}

// If a use case stopped, its share of the fixed shared tier would not go away: it would be spread
// over the other users of the pool in proportion to their own share. Returns, per use case with a
// fixed share, the cost that moves and each other user's fully loaded cost per outcome before and after.
export function sharedReallocation(ueMonth, allocated, month) {
  const out = {};
  const users = Object.values(ueMonth).filter((u) => u.fixedSharedSpend > 0);
  for (const u of users) {
    const others = users.filter((x) => x.useCase !== u.useCase);
    const base = others.reduce((s, x) => s + x.fixedSharedSpend, 0);
    out[u.useCase] = {
      moved: u.fixedSharedSpend,
      to: others.map((x) => {
        const add = base ? u.fixedSharedSpend * (x.fixedSharedSpend / base) : 0;
        return { useCase: x.useCase, added: add, from: x.costPerSuccess, to: x.successful ? (x.spend + add) / x.successful : null };
      }),
    };
  }
  return out;
}

  return {

    ptuRecommended: false,
  };
}

// Every run ends as successful, failed or discarded. Retried counts the runs that were themselves a
// retry of an earlier failed or discarded attempt, modelled on its own rate, so it is not a copy of failed.
function split(runs, o) {
  const failed = Math.round(runs * o.failed * jitter(0.08));
  const discarded = Math.round(runs * o.discarded * jitter(0.05));
  const successful = Math.max(0, runs - failed - discarded);
  const retried = Math.min(runs, Math.round((failed * o.retryFailed + discarded * o.retryDiscarded) * jitter(0.12)));
  return { successful, failed, discarded, retried };
}

}
